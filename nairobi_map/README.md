## Overview
This project showcases spatial data processing, vector styling, and map layout design using open-source QGIS software.

## Methodology & Tools
- **Software:** QGIS 3.4
- **Data Sources:** Natural Earth
- **Skills Learnt:**
  - creating a map with standard map elements like inset, grids, north arrow, scale bar  and labels
  - Viewing and changing QGIS project variables
  - How to use QGIS expressions
